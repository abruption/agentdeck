# 행동 강령 / Code of Conduct

이 프로젝트는 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)을 따릅니다. 서로 존중하고, 배려하며, 건설적으로 대화해 주세요. 문제가 있으면 GitHub 이슈나 저장소 관리자에게 알려주세요.

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful, kind and constructive. Report problems through a GitHub issue or to the maintainers.
